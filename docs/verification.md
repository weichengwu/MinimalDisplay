# 验证记录

此文区分构建、隔离逻辑验证和真实设备验收。当前状态为 **UI 待手测**，不据此承诺所有 macOS 和硬件兼容。

## 1.0.8 开源打包

显示控制源码沿用本地 1.0.7。本次整理 README、MIT 许可、上游署名、开发文档和 GitHub 构建流程；App 版本为 1.0.8，构建号为 9。许可证与技术文档随 App 分发，SHA-256 文件使用相对文件名，便于在其他机器校验。

本次验证范围为打包脚本语法、文档相对链接、公开文件清单、Release 构建、Info.plist、主程序和恢复程序签名、ZIP 完整性和 SHA-256 回读；具体发布状态见 GitHub Releases 和 Actions。未更改业务逻辑，不重复运行无关逻辑测试，也不执行 UI 自动化或真实显示切换。

## 本地开发阶段的验证

环境：Apple Silicon，macOS 27.0.1，Xcode 工具链 Swift 6.4，Swift 5 语言模式；最低部署目标 macOS 14。部署目标不等于已在 macOS 14 实测。

| 受影响行为 | 已执行的非 UI 验证 |
| --- | --- |
| 高清开关、尺寸边界、保存失败保护 | 1.0.7 对应的 3 项定向用例通过 |
| 原屏身份与恢复、离线 UUID、同次开机回退 | 1.0.2 的显示事务与身份解析共 21 项定向用例通过 |
| 离线活动判断、锁生命周期、立即重启、孤儿恢复进程清理 | 1.0.3 的 27 项直接相关用例通过 |
| 真实恢复进程生命周期 | 签名产物的 `--verify-recovery-runtime` 通过：3 次启动握手/退出/立即重启，合法主程序保护，孤儿助手清理且测试恢复记录保留 |
| 退出、移除确认倒计时、原生窗口整理 | 源码分支审查、Release 构建和包校验；真实操作待手测 |

这些是各次修改时的结果，不能相加为一次完整回归结果。测试使用模拟显示驱动、临时文件或独立测试子进程；进程验证没有创建虚拟屏或停用真实显示器。
